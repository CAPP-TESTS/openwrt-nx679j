# Android/Magisk read-only evidence acquisition

- Preserve quoting across both the host shell and the ADB remote shell. With Python subprocess argv, pass the complete remote command as `"su -c " + shlex.quote(command)`; passing `shell, su, -c, command` as separate argv does not preserve the command's grouping on the device. A loop may fail with `unexpected do`, or only its first command may run as root. Confirm root within the same quoted command before interpreting permission errors.
- Keep binary stdout free of remote stderr. Some `adb exec-out` paths merge remote stderr into the byte stream, so dd progress can append to an otherwise correct image. Use a fully quoted remote `exec dd if=... bs=... 2>/dev/null`, bounded by host timeout, then enforce the expected byte length and an independent device-side SHA-256. Suppressing stderr without those checks can hide read errors.
- Determine block device length using `/sys/class/block/<resolved-name>/size` (units are 512 bytes) or a successful `blockdev --getsize64`. `stat -c %s` reports zero for block devices and is not partition capacity. Discover the logical sector size independently for GPT parsing.
- Save only validated image files as completed backups; retain or clearly mark failed/partial reads. Persist source path, remote resolved block, expected size, actual size, device-side hash, host hash and command status.
- Read both primary and secondary GPT header/entry regions using the live logical sector size and header-derived geometry. Validate header CRC and entry-array CRC before using slot attributes. Do not regenerate GPT from historical geometry.
- Use `lsusb` for numeric vendor/product IDs; `-nn` is not a supported usbutils lsusb option. Unsupported-option output is a capture failure, not absence of the USB device.
- Treat USB interfaces backed by dummy UDC separately from the physical controller. An interface name/IP in Android does not prove host enumeration or a persistent control channel; inspect the gadget's UDC binding and verify the host-side transport.
