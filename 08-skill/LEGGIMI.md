# Le skill di questo archivio

Queste `SKILL.md` sono le procedure operative scritte durante il progetto. **Citano i percorsi
dell'albero di lavoro originale** (`/home/user/nx679j-stock/…`: `experiments/`, `port-work/`, …):
nella copia pubblicata quei contenuti stanno in altre cartelle — la tabella di corrispondenza è
in `DOCUMENTAZIONE.md`, sezione «Archivio del progetto: dove sta cosa».

Alcune skill contengono anche segnaposto `«redacted»` al posto di nomi di file o percorsi del
device: vedi la nota sulle convenzioni nel `README.md`.
